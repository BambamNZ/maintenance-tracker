# Contribution guidelines

This is currently a solo homelab project, but the same discipline applies
to future-me as much as anyone else:

1. Branch from `main` for any change.
2. Update `README.md` if behaviour changes.
3. Lint clean with `ruff format .` && `ruff check .` before committing.
4. Test against real hardware before merging - see the testing checklist
   in `README.md`.
